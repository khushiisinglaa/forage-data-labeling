# Forage Data Labeling Simulation

Virtual job simulation completed on Forage: a hands-on introduction to labeling, privacy, and quality for real-world AI.

## What I did

**1. Labeled support messages by intent**
I read customer messages and chose the main request for each one: Billing (refunds, charges, subscriptions), Technical (errors, bugs, login issues), Account (profile changes, access updates), or Other.

**2. Labeled sentiment**
I marked how the customer felt: Positive (thanks, satisfaction), Neutral (just information), or Negative (frustration, complaints, urgency). This helps an AI reply in the right tone.

**3. Flagged PII**
I spotted personal details such as names, emails, phone numbers, and account numbers, and set the PII flag to "Yes". I did not copy or store any of this information.

**4. Wrote notes for edge cases**
For messages that were unclear or mixed, I wrote 1 to 2 sentence notes to explain why I chose a certain intent and sentiment. This keeps labels consistent across a team.

**5. Reviewed labels using Keep / Fix / Flag**
I checked label sets made by others. I kept the correct ones, fixed the wrong ones with a reason, and flagged the unclear ones.

**6. Suggested a guideline improvement**
I proposed one small change to the One Page Guidelines to make labeling clearer for future labelers.

## Skills
Data labeling, quality control, PII awareness, guideline writing, attention to detail
